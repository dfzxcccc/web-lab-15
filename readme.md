# Лабораторна робота №15
## Обробка даних на клієнті та робота з формами

У межах лабораторної роботи до проєкту додано клієнтську обробку даних та роботу з формами:
- Реалізовано живий пошук товарів у каталозі з нормалізацією (`trim`, `toLowerCase`) через подію `input`.
- Налаштовано підрахунок кількості та суми товарів у кошику за допомогою методу `reduce()`.
- Створено форму оформлення замовлення зі збором даних через `FormData`.
- Здійснено санітизацію тексту та клієнтську валідацію полів за допомогою регулярних виразів (`RegExp`).
- Додано динамічний перерахунок знижки за промокодом (`SALE10`).
